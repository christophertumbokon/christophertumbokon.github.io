Projects

STM32 Temperature Monitoring and Automatic Fan Cooling

An in-progress embedded project using an STM32L476RG and a BME280 temperature sensor to monitor temperature and automatically control a cooling fan. The system is designed to use PWM for fan speed control, an ADC for an adjustable temperature setpoint, and an LCD to display system information.

STM32 C I²C PWM ADC

Autonomous Rover with ESP32-S3

An ESP32-S3 rover project using FreeRTOS for real-time task scheduling, motor control, and sensor integration. The rover uses camera input for on-device machine learning, obstacle avoidance, and visual tracking, with wireless telemetry for monitoring.

ESP32 FreeRTOS TinyML

Mobile Robotics Research

Undergraduate research involving TurtleBot 4 and Stretch mobile robots in a multi-robot system. The work includes configuring ROS 2 navigation and sensor pipelines, developing robot-to-robot communication, and debugging Linux-based networking.

ROS 2 Robotics Linux
